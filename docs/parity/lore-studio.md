# Паритет Лор-студии (M23) с окном «Миры и лорбуки» SillyTavern и Lore Library DES

Источник списка функций — опись [`research/parity-lore.md`](../research/parity-lore.md) (SillyTavern 1.19.0, DES 2.6.0), все 233 пункта L-001…L-233 в её порядке. Состояние — этап 2, оболочка и слой данных Лор-студии (`src/features/loreStudio/`, кроме `form/**`), 2026-10-04.

Статусы:

- ✅ — есть в коде и проверено unit-тестами (оболочка — `tests/features/loreStudio/*.test.ts`, `tests/domain/lore-studio-*.test.ts`; форма записи — `tests/features/loreStudio/form/**`, статусы формы — по отчёту её автора); вживую ещё не проверялось;
- ✅ вживую — проверено на живом ST (ставит ведущий после проверки, см. «Проверить вживую» в конце);
- ❌ — не сделано, причина указана;
- N/A — к Лор-студии не относится, причина указана.

«Перехват» — настройка «Открывать Лор-студию кнопкой „Миры и лорбуки“» (`takeoverButton`, по умолчанию выключена: по плану M23 включается, когда таблица зелёная). До перехвата кнопки персонажа, чата и персоны открывают классическое окно, как и раньше.

Как устроено (для сверки с таблицей):

- **Слой данных** — `store.ts` (`LoreStore`, `app.modules.api('loreStore')`): очередь сохранений по книгам, только `saveWorldInfo(имя, данные, true)`, после каждой записи `reloadWorldInfoEditor` и сброс кэша Lore Library DES; глубокие копии при чтении; зеркало `originalData` через `setWIOriginalDataValue`/`deleteWIOriginalDataValue` ST; незнакомые поля сохраняются; каждое изменение — в журнал Maestro с откатом (свои цели `lore-studio-entry`, `lore-studio-book`, `lore-studio-binding`, `lore-studio-settings`; `lore-entry` остаётся за M5/M22); прежние версии записей — в файле `maestro-lore-history-<hash>.json` (20 на запись); внешние `WORLDINFO_UPDATED` — событие `onChange` и версия «изменено вне Maestro».
- **ST** — `st-lore.ts`: глобальный выбор через обработчик ST на `#world_info` (`onWorldInfoChange('__notSlashCommand__')`), настройки — через элементы классической панели и то событие, которое слушает ST; привязки — `charUpdatePrimaryWorld` / `writeExtensionField`, `charSetAuxWorlds`, `chat_metadata` + `saveMetadata`, поля персоны как в `personas.js`; импорт — `importWorldInfo` ST; экспорт — `download` ST.
- **DES** — `des-lore.ts`: модули `campaignManager`, `lorebookAPI`, `autoLink`, `persistence` по URL скрипта DES (те же экземпляры); DES остаётся владельцем (Q32).
- **Окно** — `studio.ts` и `view-*.ts`; форма записи (`form/**`) подключается через `form-api.ts`; перед сменой записи, книги, вкладки и закрытием окна (×, Escape через `onClosing` Popup, «Классический редактор») оболочка спрашивает форму (`setLeaveGuard`) о несохранённом.
