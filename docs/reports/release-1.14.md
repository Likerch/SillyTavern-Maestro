## Ограничения

- Состояния и инвентарь принимаются только у механик, где эти части включены (`statuses` / `inventory`); механики, сохранённые до 1.14, их не получают сами — дополняются в конструкторе.
- Статус-блок показывается только под последним ответом.
- Сообщения рассказчика не записываются в журнал — это обычные сообщения чата.
- Правила времени работают при дате и времени в трекере DES; без них — только правила «за ход».
- Не больше трёх бросков по просьбе модели за ответ.
