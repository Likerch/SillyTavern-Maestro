# Выпуск 1.33.0 — отчёт

План: [`agents-plan.md`](../agents-plan.md), §3.19 и §5 «1.33.0 — картинки». Дата: 2026-11-12. Вместе с NAI Studio 0.16.0
(отдельный репозиторий, коммит `49b9558`).

## Что сделано

### NAI Studio 0.16.0

- **«Кто пишет метки»** (настройка `markers.writer`): «Модель чата» (как раньше, по умолчанию), «Иллюстратор»,
  «Иллюстратор, если модель чата не поставила метку». Настройка действует, только пока другое расширение
  зарегистрировало иллюстратора (`registerIllustrator`). Без него NAI Studio всегда ведёт себя как «Модель чата», так
  что выключение агента возвращает метки основной модели.
- **Режим «Иллюстратор»**:
  - своя инструкция NAI Studio не вставляется;
  - блок правил пресета вырезается из промпта chat completion настоящей генерации. Блок — самый внутренний элемент
    вокруг примера `data-nai`, кроме HTML самого ответа: так твой `<images>…</images>` из «Стека». Вырезается не
    больше 6000 символов; опустевшее сообщение убирается целиком;
  - вырезанные правила запоминаются для иллюстратора (`markerRules`); если их не было — своя инструкция NAI Studio.
  - В обоих режимах иллюстратора автоиллюстрация по отрывку выключена.
- **`requestImage`**: метка иллюстратора встаёт после абзаца, в котором кончается фраза `after` (поиск нестрогий; не
  найдено — в конец), и рисуется ровно как метка ответа:
  - паспорта, интерпретатор, стиль, непрерывность места;
  - вердикт ворот качества, «Повторить», лимит меток на ответ, правила цены меток.
  - `freeOnly` — только бесплатно. Метка помечена `by: 'illustrator'`.
- `messageMarkers`, `drawPicture` (картинка не в сообщение, для обложек), `generateCardAvatar`.
  - Аватар карточки рисуется только бесплатно. Перед заменой прежняя картинка сохраняется вместе с данными карточки в
    `user/images/avatar-backups`; если копия не сохранилась, ничего не меняется.
- `generateBackground` с `freeOnly`; поза в подсказке сцены (`poses`).
- Настройка в разделе меток с подсказкой, README (en/ru), CHANGELOG; 748 тестов (было 736).

### Maestro

- **Картинки через «Предложения»**: новые приёмники вместо отдельного типа результата.
  - Приёмник может сказать, что сейчас он не нужен (`ProposalReceiver.available`). Агент, у которого все приёмники
    не нужны, не запускается вовсе: ни запроса, ни строки в журнале. Поэтому Декоратор и Обложки ничего не стоят в
    ходы, когда работы нет.
- **Иллюстратор** (`nai.illustrate`):
  - видит правила картинок из пресета (новый источник `markerRules`), гардероб, мизансцену, трекер DES, места, два
    прошлых сообщения и ответ;
  - отвечает объектом метки — тем, что основная модель кладёт в `data-nai` — и фразой, после которой ставить;
  - дальше метка идёт путём NAI Studio без изменений;
  - работает только в режиме NAI «Иллюстратор» или в «…если модель не поставила метку» (для ответа без метки);
  - Maestro регистрируется иллюстратором NAI Studio ровно пока такой агент включён в этом чате.
- **Декоратор** (`backgrounds.agentGenerate`):
  - срабатывает, только когда M29 не нашёл фон в библиотеке для текущего места: один раз на место и чат;
  - агент пишет, как место выглядит сейчас;
  - NAI Studio рисует фон, по умолчанию только бесплатно; M29 привязывает его к месту и ставит через свою автономию
    `backgrounds.set` (с журналом и откатом).
- **Портретист** (`nai.portrait`):
  - новые лица сцены без паспорта (трекер DES и мизансцена, кроме игрока и самой карточки) показываются агенту по
    одному разу (источник «Лица без портрета»);
  - паспорт пишет генератор NAI Studio и кладёт в этот чат — с журналом и откатом;
  - с DES лицо получает портрет (`requestDesPortrait`).
- **Аватар карточки** (`nai.cardAvatar`): шаблон «по кнопке». Всегда с вопросом (`neverAuto`), старая картинка
  сохраняется копией.
- **Обложки глав** (`chronicle.cover`):
  - глава летописи без обложки получает картинку через `drawPicture`;
  - обложка хранится в документе чата `chronicle-covers`, видна в «Летописи» на главе, отменяется через журнал.
- **Вкладка «Картинки»** в окне «Агенты»:
  - «Кто пишет метки (NAI Studio)» и что действует сейчас;
  - «Картинки агентов могут тратить Anlas» — по умолчанию выключено (В15): фоны, картинки и обложки агентов только
    бесплатные;
  - **сравнение вслепую**:
    - до 20 ответов чата с меткой основной модели;
    - Иллюстратор пишет к каждому свою метку пробным прогоном;
    - обе метки рисуются заново одним путём NAI Studio, только бесплатно;
    - пары идут в случайном порядке: «Левая лучше / Одинаково / Правая лучше»;
    - итог и вердикт запоминаются;
    - пустой прогон называет причину.
- **Мизансцена → картинки**: подсказка сцены режиссёра для NAI Studio несёт позы M45 для последнего ответа.
- **Шаблоны** (группа «Картинки»): Иллюстратор, Декоратор, Портретист, Аватар карточки, Обложки глав.
  - **Набор «Кино»**: + Декоратор, Портретист, Обложки глав.
  - Иллюстратора нет ни в одном наборе, пока он не выиграет сравнение (§3.19 п. 6).
- Мок-модель: ответ на `agent_proposals` для картинок и флаг `[mock:image]` (метка основной модели в ответе). На
  стенде закреплена NAI Studio 0.16.0.

## Расхождения с планом

- **Тип результата «image»** не заведён: картинки идут приёмниками «Предложений» (один механизм — журнал, Inbox,
  автономия, проверка «нужен ли сейчас»).
- **Спрайты эмоций по кнопке** не сделаны: генератор спрайтов NAI Studio живёт в своём окне. Агенту там нечего
  решать, кнопка есть в самой NAI Studio.
- **Аватар персоны** агентом не рисуется: это уже делает «Создать персону» (M41) через `generatePersonaAvatar`.
- **«Платные с вопросом» (В15)**:
  - для фонов вопрос о цене задаёт сама NAI Studio, когда «могут тратить Anlas» включено;
  - для меток иллюстратора и обложек действует лимит меток NAI Studio без вопроса (как у меток основной модели).
- **Вариант фона по времени суток** запоминается за местом, как у кнопки M29: первый фон места — основной,
  следующие — варианты.

  - «Картинки» → «Иллюстратор»: основной запрос ушёл без блока `<images>` и без инструкции NAI. Запрос Иллюстратора
    получил блок `<images>` из «Стека» с подставленными `{{nai_characters}}`. Его метка встала в ответ заглушкой с

    NAI».
  - «Основная модель»: блок `<images>` вернулся в основной запрос, Иллюстратор не вызывался.
  - Сравнение вслепую:
    - кандидатов два — ответ, нарисованный самим Иллюстратором, не попал;
    - три пробных прогона ушли модели Иллюстратора;
    - пар нет, потому что картинки стоили бы Anlas, и вкладка так и пишет.
  - Найдено и исправлено на стенде: в кандидаты попадали метки самого Иллюстратора (теперь `by: 'illustrator'`);
    пустой прогон молча возвращал кнопку.
- **Не проверено:**
  - настоящие картинки — на стенде нет NovelAI;
  - сравнение вслепую на 20 твоих ответах — это приёмка, её делаешь ты;
  - Декоратор, Портретист и Обложки вживую (только тестами).

## Ограничения

- Иллюстратор работает после ответа: картинка появляется на несколько секунд позже, чем от метки основной модели, и
  во время потока ответа ничего не рисуется.
- Блок правил пресета вырезается, только если он обёрнут в элемент (`<images>…</images>`). Блок без обёртки
  остаётся в промпте — тогда лучше оставить режим «Основная модель» или обернуть блок.
- Портретист смотрит на лица сцены последнего ответа; лицо, которое уже показано агенту, повторно не предлагается
  до перезагрузки страницы.
