# Выпуск 1.30.0 — отчёт

План: [`agents-plan.md`](../agents-plan.md), §4.6 и §5 «1.30.0 — пакеты и экономия». Дата: 2026-11-09.

## Что сделано

- **Пакеты** (`domain/agents/batch.ts`, `AgentRunner.runMany` / `runBatch`):
  - группа — агенты одного момента, одного профиля, одних рассуждений, одного ответа в фокусе, у всех включено
    «Отправлять вместе»; правки ответа и пробные запуски — всегда отдельно;
  - запрос: рамка для нескольких задач → объединённые источники (каждый один раз, самая длинная версия, стабильные
    первыми) → блок `<agent_task id="aN">` на агента с его поручением и формой ответа → один JSON-объект
    `{"a1": …, "a2": …}`; схема — свойство на агента;
  - длина ответа — сумма длин агентов (не больше 6000), температура — средняя;
  - выпавший из ответа или с частью не по форме агент — повтор отдельным запросом; транспортный сбой или таймаут
    пакета — сбой у всех, без повтора;
  - цена и токены пакета делятся по длине поручений;
  - пакетами идут «после ответа» (кроме правок), «заранее», «вместе с ответом», «при отправке» и агенты по
    расписанию, которым пора в один момент (одна задача в очереди на группу).
- **Вопрос дешёвой модели** (`features/agents/gate.ts`): `AgentDef.gate`, задача `agents.gate`, строка профиля
  «Агенты: вопрос „нужен ли сейчас“»; ответ `{run}`; пропуск только при явном `false`; пропуск пишется в журнал.
- **Оценка цены хода** (`domain/agents/cost.ts`): средняя цена последних 10 платных запусков × запусков за ход
  (1 у моментов хода, 1/N у «раз в N сообщений», 0,1 у агентов только по событиям, 0 у кнопочных).
- Одиночные запуски одного момента — не больше трёх одновременно.

## Решения по ходу

- Сначала группировал и по температуре — на стенде «Редактор-критик» (0,5) и «Варианты действий» (0,9) так и не
  встретились в пакете. Для пакета важны профиль и рассуждения; температура стала средней по пакету (подсказка в
  редакторе это говорит).
- Встроенные агенты в пакеты не идут: их запросы собирают и отправляют сами модули. План (В4) про «встроенных в
  пакете по умолчанию» относится к своим агентам, которым ты включишь «вместе».

## Проверки

- Тесты: 6606 пройдено, 5 пропущено. Новые: пакет, разбор, доли цены, группировка, оценка хода (6 в домене);
  пакет из двух агентов одним запросом, общая температура, повтор выпавшего, отдельные без «вместе», вопрос
  дешёвой модели «нет» и сбой вопроса (5 на поддельном ST).
- `tsc`, ESLint, Prettier — чисто; сборка `dist/` — есть.
- Стенд: «Редактор-критик» и «Варианты действий» с «вместе» → на живом ходе ушёл один запрос `agent_batch` с двумя
  блоками задач; «Варианты», которым имитация ответила не по форме, сами переспросились отдельно. Шапка списка:
  «Твои агенты добавляют к ходу ≈ $0.0010. Ещё не оценены: 1».
- **Не проверено:** настоящая модель (насколько хорошо она держит несколько задач в одном ответе — смотреть в
  журнале запусков).

## Ограничения

- Оценка цены — по журналу этого чата; в новом чате агенты «ещё не оценены», пока не поработают.
- Встроенные агенты в оценку хода не входят (их частоту решают модули).
