## Не проверено вживую (проверено тестами)
- Генерация паспорта и фона в NAI Studio (на стенде нет ключа NovelAI; вызывать NovelAI в проверках нельзя).
- Архив CarrotKernel из «Оформить»: выбор тегов настоящей моделью по большому словарю, появление архива в CK.
- Перенос записи канона в книгу карточки.
- Состояния мест в паспорте локации (у мест эталонного чата нет паспортов локаций NAI).
- Отложенные карточки нарядов из ревизии с настоящей моделью.

## Найдено и исправлено при сборке
- NAI Studio рисовал описание наряда из трекера DES вместо активного наряда паспорта, поэтому наряды гардероба не влияли на картинки персонажей DES. Теперь гардероб запоминает формулировки трекера в наряде, а NAI Studio 0.12.1 узнаёт по ним наряд.
- Обновление записи канона стирало паспорт, хранящийся в ней. Теперь паспорт сохраняется.
- «Сделать вручную» у записи без типа всегда предлагал вид «персонаж». Теперь вид берётся из модели мира («Old Fort» — место).
- Запись канона из «Оформить» повторяла внешность и отношение (детали трекера и модель мира). Повторы убраны, отношение берётся из модуля отношений.
- Персонаж, который входит в сцену уже в новом наряде (или у которого поле наряда появилось посреди чата), не получал наряд: сигналы считают первое значение исходным. Теперь гардероб сам сверяет поле наряда двух зафиксированных ходов.
- Имитация модели не умела наряды: добавлена метка `[mock:outfit:Имя=наряд]`.

## Решения по ходу
- Текст записи канона из «Оформить» — как в источниках (детали DES-RU по-русски); ключи — русские формы.
- «Maestro · архив» CarrotKernel сам не увидит: у CK нет способа добавить книгу-репозиторий извне без перезагрузки. План и статус подсказывают отметить её в CK.
- Фон, не набравший порога, сам не ставится (например, «tavern day» ночью — 1,5); его можно поставить кнопкой.
- Если маркер картинки сам описывает, во что одет персонаж, побеждает описание маркера (так NAI Studio работает с 0.9.10); наряд гардероба тогда применяется, только если описание маркера совпало с запомненной формулировкой.
