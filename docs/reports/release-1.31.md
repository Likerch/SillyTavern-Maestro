# Выпуск 1.31.0 — отчёт

План: [`agents-plan.md`](../agents-plan.md), §3.18 и §5 «1.31.0 — предложения и создатели». Дата: 2026-11-09.

## Что сделано

- **Тип результата «Предложения»** (`proposals`): `ProposalsOptions {receivers, max}`; форма ответа перечисляет
  только разрешённые приёмники с их описанием и полями; схема — `{"proposals": [{kind, why, data}]}` с перечнем
  видов; разбор берёт разрешённые виды до предела. Пакеты (1.30) передают приёмники каждому агенту.
- **Реестр приёмников** (`core/proposal-receivers.ts`): модуль в `init()` регистрирует вид предложения (он же вид
  автономии), описание для модели, JSON-схему, автономию по умолчанию, `toProposal` и `apply`. «Агенты» проверяют
  данные схемой, зовут `toProposal`, отправляют в `autonomy.decide` и регистрируют применение карточек «Входящих»
  для каждого приёмника.
- **Приёмники:**
  - канон — `canon.agentEntry` (новая запись канона чата, происхождение `agent`, ключи со словоформами, без
    повторов известных имён) и `canon.agentEdit` (правка записи лора поверх, только в чате; ссылка `Книга#номер`);
    откаты: снять запись / вернуть прежнюю правку или снять;
  - календарь — `calendar.agentPromise` (обещание; откат — «отменено», удаления у календаря нет).
- **Шаблоны**: Создатель персонажей, Редактор персонажей, Биограф, Картограф, Летописец мира, Хранитель тайн;
  набор «Мир растёт».
- **Источники**: `knowledge`, `worldNames`, `places`; у «Лора хода» — ссылка на запись.
- Происхождение канона `agent` (`CANON_ORIGINS`, подписи в каноне и Лор-студии).

## Расхождения с планом

- **Карточки ST.** По твоему уточнению (В14) Создатель персонажей не создаёт карточек. Правок текста карточки нет
  вообще: Maestro и раньше нигде не менял описание карточки, поэтому «Редактор персонажей» правит запись лора
  персонажа в этом чате. Приёмника `st.card.edit` нет.
- **Профиль Dramatis.** У Dramatis нет API «заполнить поля» / «поднять уровень» — приёмник `dramatis.profile`
  переносится в 1.34, вместе с переводом Dramatis на агентов (нужна доработка Dramatis).
- **Паспорт NAI** как приёмник — в 1.33, вместе с картинками.
- **Инструменты чтения для агентов** (агент сам смотрит лор, канон, досье по ходу ответа) — переносятся в 1.34,
  вместе с общим циклом инструментов ассистента. Пока агент видит то, что ему дают источники.
