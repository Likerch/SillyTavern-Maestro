# Отчёт: этап 0 — каркас

Дата: 2026-10-04. Стенд: SillyTavern 1.19.0 (из `st-local-docker/src-1.19.0`, без Docker), DES 2.6.0, CarrotKernel 1.0.0, BunnyMo V3.0 (13 лорбуков), Qvink 1.3.29, NAI Studio 0.9.10, DES-RU 0.7.0, Lorebook Localizer 0.1.0, имитация модели.

| Задача | Результат |
|---|---|

| 0.2 Слой ST (`src/host`) | контекст, события с управлением порядком (первым/последним, переутверждение), загрузка модулей ST по адресу, 19 проверок возможностей ST, единый перехват `fetch` |

| 0.7 Учёт стоимости | фактическая стоимость основной генерации, Qvink и своих запросов (по сигналу запроса), Anlas, дневной файл, потолок фоновых задач, общий лимит |

| 0.10 Одноразовые флаги и вставки, хуки | флаги и вставки ставятся перед генерацией и стираются после; хуки отключения и очистки; конвейер хода (`turn:committed`, `reply:ready`, `message:invalidated`) |
| 0.11 Пульт | кнопка в верхней панели со счётчиком, пункт меню палочки, блок в панели расширений; вкладки Обзор, Входящие, Здоровье, Задачи, Журнал, Настройки; мастер первого запуска; телефонная раскладка |

| 0.14 Стенд | `tools/stand` (setup/start/stop/reset/status/run), имитация модели `tools/mock-llm` (сценарии брака, листы, JSON-схемы, стоимость), синтетические фикстуры (чат 320 ходов, книга мира на 49 записей с рекурсией, архив CK, карточка), снимки промпта |

## Известные ограничения
- На стенде нет пресета Marinara v10 (используется Default); `setup --preset <файл>` подставит его.
- Серверный плагин NAI Studio на стенде не ставится (серверные плагины выключены) — для Maestro не нужен.
- Автопрогон эталонного чата по ходам через браузер — в следующих этапах (снимки промпта готовы).
