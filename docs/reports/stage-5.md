## Не проверено вживую (проверено тестами)

Шаги — в конце таблицы паритета:
- замена раздела Prompt Manager кнопкой и возврат;
- полный круг правки блока: PM, `/getpromptentry`, настоящая генерация;
- переключение пресетов через `/preset` и профили подключения (черновики-версии);
- конфликт из трёх версий при обновлении Marinara;
- перенос правок в слой без ключей подключения;
- стоп-строки сценариев с `\n`;
- телефон.

## Решения по ходу
- Замена раздела Prompt Manager по умолчанию выключена: как и с Лор-студией, её включаем, когда обязательные пункты проверены вживую.
- Удаление базового блока в режиме слоя записывается как «выключить» (в слое нет операции удаления); блоки, сделанные вне студии и не сохранённые, правятся только в рабочей копии.
- Хранилище само учитывает слой: черновик сравнивается с «база + слой», «Сохранить базу» пишет базу без слоя, «Сохранить как» запекает слой.
