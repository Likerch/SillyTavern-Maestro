# Отчёт: этап 4 — ревизия и живой канон (выпуск R3, 1.0.0)

Дата: 2026-10-04. Стенд: ST 1.19.0, DES 2.6.0, CK 1.0.0, BunnyMo V3.0, Qvink 1.3.29, DES-RU 0.8.0, Localizer 0.2.0, NAI Studio 0.10.0, имитация модели (профиль подключения «Maestro bench» для фоновых задач), эталонный чат на 320 ходов.

## Что сделано

| Задача | Модуль | Результат |
|---|---|---|
| 4.1 Сигналы и фиксация при отправке | S4 `signals` | При отправке прошлый ответ фиксируется; сравнение с прошлым ходом идёт в простое браузера, не на пути отправки. Сигналы: отношения, стойкая внешность и одежда, место (через реестр мест), пропуск времени, конец сцены, квесты, кто пришёл и ушёл, новые алиасы DES, новые имена, память Qvink. Свободный текст засчитывается через два хода; однотипные сигналы сворачиваются. У каждой записи — отпечаток сообщения, поэтому свайп, правка и удаление откатывают ровно то, что дал ответ. |
| 4.2 Ревизия и «Входящие» | M8 `revision` | Запуск по ≥ 3 сигналам, раз в N сообщений, в конце сцены или командой `/maestro-revise`. Дешёвая модель получает строгую JSON-схему, досье затронутых сущностей, память Qvink и очищенные зафиксированные ходы; данные чата огорожены как недоверенные. Ответ проверяется перед записью: теги только из словаря паков, паспорт — английские теги без анатомии вне слоя NSFW, имя архива не меняется, «было» не изменилось. Маршрутизация: канон чата, теги архива CK через канон, паспорт NAI уровня чата, прозвища чата, заметка для алиаса DES, летопись, реестр мест; новое — в живой канон; наряды, обещания, секреты — отложенными карточками. «Входящие» сгруппированы по сущностям; можно изменить значение на месте, выбрать «Всегда так» или принять всё. |
| 4.3 Проверка противоречий | M26c `contradictions` | Правила (имена, числа, даты, отрицания) на русском и английском; при сомнении — дешёвая модель. Внутри фоновой задачи модель вызывается напрямую, без очереди, чтобы задача не ждала сама себя. |
| 4.4 Живой канон | M26 `livingCanon` | Дешёвый поиск новых имён после ответа. После фиксации хода — пробная запись канона: не больше 3 за ход, русские ключи через DES-RU, похожее склеивается. Подтверждение по правилам плана: упомянул сам, принял, всплыло без записи в промпте, 10 ходов без противоречий. Пакетное извлечение пишет английский текст. Свайп убирает пробное, подтверждённое остаётся. Счётчики для замеров. |
| 4.5 Летопись, автопамять, «Ранее в истории…» | M9 `chronicle` | Главы из воспоминаний Qvink, выпавших из долгой памяти: ключи «И» (участник и место, предмет или второй участник), бюджет канона, склейка мелких глав. Maestro — единственный владелец отметки «запомнить» в Qvink: ставит её во всех свайпах и не трогает отметки пользователя. «Ранее в истории…» после перерыва: один раз, только ведущей вкладке. |
| 4.6 Замеры | M21m `metrics` | Вкладка «Замеры» с десятью критериями R3 и экспортом в Markdown и JSON. В слое событий учитывается время каждого обработчика Maestro, поэтому задержка считается по собственному коду Maestro, а работа ST показана отдельно. Скрипт стенда `tools/stand/measure.mjs`. |

## Найдено и исправлено при сборке
- **Досье и листы путали Александра и Александру.** Падежная форма «Александра» совпадала с другим персонажем. Досье показывало оба архива, `!fullsheet Александр` взял бы образцом оба. Теперь точное имя важнее падежной формы, а досье ищет архив только по точному имени.
- **Запросы NAI Studio записывались в расходы Qvink.** Теперь их узнают по имени JSON-схемы `nai_*`.
- **Критерий задержки считался по всему пути ST.** Теперь время каждого обработчика Maestro учитывается в слое событий, и критерий считается по коду Maestro.
- **Пробные факты живого канона работали после выключения модуля** (нарушение P11). Теперь канон пропускает их, пока M26 выключен.
- **Ядро автономии и «Входящие».** Добавлены `setLevel` и `isNeverAuto`, поэтому «Всегда так» не работает для видов, которые никогда не делаются сами. «Входящие» сообщают модулю об отклонении карточки.
- **Стыки модулей.** Сигналы не считают сигналы ревизии. Проверка противоречий из фоновой задачи не ждёт очередь. Ревизия передаёт новое в живой канон через `propose`.

## Не проверено вживую (проверено тестами)
- Живой канон на настоящих русских ответах: доля ложных имён, подтверждение «всплыло без записи в промпте».
- Глава летописи при малом бюджете долгой памяти Qvink; «Ранее в истории…» после перерыва; отметка «запомнить» в свайпе 0.
- Карточки ревизии во «Входящих» с настоящей моделью: изменение на месте, «Всегда так», маршруты в паспорт NAI и архив CK.
- Задержка на телефоне, две вкладки.

## Решения по ходу
- Каждый перелом в отношениях получает отметку «запомнить». Если на живой игре это окажется слишком часто, порог поднимем.
- Ревизия по умолчанию: факты канона, теги и внешность — во «Входящие»; прозвища чата, события летописи и состояние места — «Само» (§8).
- Выпуск R3 (1.0.0) собран, но не выложен на сервер: выкладка — только по твоему разрешению, и все вкладки ST должны быть закрыты. Для него нужны DES-RU 0.8.0, Localizer 0.2.0 и NAI Studio 0.10.0 — их коммиты тоже пока локальные. Для ревизии, живого канона и проверки противоречий нужен профиль подключения для фоновых задач (Настройки → Профили).
