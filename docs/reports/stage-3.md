# Отчёт: этап 3 — модель мира, досье, места (выпуск R2)

Дата: 2026-10-04. Стенд: ST 1.19.0, DES 2.6.0, CK 1.0.0, BunnyMo V3.0, Qvink 1.3.29, DES-RU 0.8.0, Localizer 0.2.0, **NAI Studio 0.10.0**, имитация модели, эталонный чат на 320 ходов.

## Что сделано

| Задача | Модуль | Результат |
|---|---|---|
| 3.1 Модель мира и опознание имён | M7w `world` | Сущности собираются из всех хранилищ. Дешёвые источники: карточки, персона, состав DES, алиасы DES и DES-RU, падежи, паспорта NAI (с изменениями чата), места. Лениво читаются лорбуки: записи с типом, архивы CK, канон. Склейка идёт по одинаковому имени, группам алиасов и карте алиасов чата. Русская форма английского имени не угадывается. Сомнительные совпадения (общее имя, короткое имя при полных, алиас у двух сущностей) уходят во «Входящие». Пересборка идёт после фиксации хода и после генерации, а не на пути отправки. Решения о склейке хранятся в документе чата. |
| 3.2 Досье | M7 `dossier` | Персонаж, место, персона. Разделы: DES, лор с каноном, архив CK и теги (MBTI с H/U), паспорт NAI с изменениями чата, падежи, Qvink, RAG, последний лист. Структурная сверка с исправлениями через автономию. Паки BunnyMo никогда не исправляются (P13). Сверка ИИ — фоновой задачей, только в ведущей вкладке, с ценой. «Разнести» превращает одну правку в предложения по хранилищам. Команда `/maestro-dossier`. |
| 3.3 Места | M24 `places` | Реестр мест чата. Захват по локации DES при фиксации хода, вложенность угадывается по словам места. Правило двух ходов; похожие названия уходят во «Входящие». Визиты: кто был, дата истории, события. Свайп, удаление и правка точно откатывают то, что ответ изменил. Описание места — запись канона типа «место». Мост `MAESTRO_PLACES` для NAI Studio. |
| 3.4 Граф отношений (данные) | M19 `relations` | Отношение каждого персонажа к персоне по трекеру DES. Перемена записывается при фиксации хода; свайп ничего не оставляет; удаление в середине перечитывает историю. Первая сборка старого чата идёт в фоне. |
| 3.5 Режим BunnyMo | M35b `bunnymoMode` | Словарь тегов всех паков: подтягивающие и информационные записи, конфликты версий, дубли, теги без пака. Менеджер паков: версии и выбор паков на чат (подавлением на лету, файлы и глобальные включения не меняются), сравнение с новым файлом. Целостность: ядро и его версия, пак в репозиториях CK, обёртка тегов CK, копии `.carrot_backup`, глобально включённые канон и книга чата. Редактор листов архивов с проверкой тегов по словарю; правка только там, где менялось. Список правок на лету. Команда `/maestro-bunnymo`. |
| 3.6 NAI Studio 0.10.0 | §16 | Паспорта уровня чата (переключатель «Карточка / Этот чат» в редакторе). `NAI_STUDIO_API`: паспорта, наряды, состояния, события «паспорта сохранены» и «картинка готова». Несколько поставщиков сцены. Непрерывность мест по id места Maestro. Коммит 8cbd6b2 в репозитории NAI Studio, 521 тест. |

## Найдено и исправлено при сборке
- Агенты модели мира и досье вызывали несуществующие методы API NAI Studio. Получили точный контракт и переписали чтение и запись паспортов.
- Пара «BSM-5 + CoT Lenses» считалась конфликтом версий: настоящие названия записей начинаются с эмодзи («💊 CoT LENS — …»), и проверка их не узнавала. Исправлено в правилах и в Докторе, тесты дополнены.
- Выбор паков на чат теперь применяется до правил паков. Иначе правило могло оставить копию из выключенного пака, и запись пропадала совсем.
- «Входящие» сообщают модулю об отклонённой карточке («это разные люди», «это не то же место»).
- Лор-студия открывается из досье, мест и режима BunnyMo сразу на нужной записи; у книг BunnyMo и архивов в студии есть кнопка режима BunnyMo.

## Не проверено вживую (проверено тестами)
- Склейка и разделение сущностей через «Входящие», прозвища чата, откат из журнала.
- Свайп, удаление и правка ответа для мест и отношений; переход ведущей вкладки.
- Сверка ИИ в досье: на стенде нет профиля подключения для фоновых задач.
- Паспорта уровня чата в редакторе NAI Studio, событие «картинка готова», поставщик сцены от Maestro.
- Редактор листов архивов, сравнение пака с файлом, находки целостности.

## Решения по ходу
- «Александру» — и дательный падеж «Александр», и винительный «Александра». Модель мира отдаёт такую форму первому совпадению; точное имя всегда важнее падежной формы.
- DES-RU склоняет «Элизабет» как мужское имя, поэтому «Элизабетой» не опознаётся по формам. Упоминания в тексте модель мира всё равно находит: после кириллического имени допускаются до двух букв.
- Захват мест читает последние 20 ответов при первом открытии чата; дальше — по одному ходу при фиксации.
- Выпуск R2 (0.2.0) собран, но не выложен на сервер: выкладка — только по твоему разрешению. Для R2 нужны DES-RU 0.8.0, Localizer 0.2.0 и NAI Studio 0.10.0 — их коммиты тоже пока локальные.
