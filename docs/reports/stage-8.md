# Отчёт: этап 8 — режиссура (выпуск 1.4.0)

Дата: 2026-10-05. Стенд: стек этапа 7, новый движок макросов включён, имитация модели.

## Что сделано

| Часть | Модуль | Результат |
|---|---|---|
| Тип сцены | M13 `director` | Ответ читается после `reply:ready`, при фиксации хода результат применяется к следующей генерации (P15). Учитываются словари RU/EN, трекер DES, сигналы пропуска времени и твоё сообщение: резкое действие (атака, поцелуй, «прошло три дня») решает само, слабое добавляется с весом 0,6. При сомнении — дешёвая модель. Устойчивость: тип меняется сразу при уверенности ≥ 0,85, иначе после двух ходов подряд. Можно задать тип самому. |
| Флаги для пресета | M13 | На одну генерацию: `maestro_scene_<тип>`, `maestro_reply_short/medium/long`, `maestro_explicit`, `maestro_lang_ru/en`, `maestro_picture_moment` (с учётом платности картинок NAI). После генерации снимаются. Каталог флагов доступен через API (`catalogue()`). Подсказка о месте для NAI Studio — через поставщика сцены. |
| Темп и повороты | M14 | Застой — то же место, ничего не происходит, повторы, разговор по кругу (по умолчанию 4 хода). Тогда — заметка режиссёра (в чате, глубина 0) с поворотом из открытых квестов DES и незакрытых нитей. Не чаще раза в 6 ходов («Сбалансированный»), раза в 4 («Кино»), в «Экономном» заметок нет. Молчит, когда сюжет ведёшь ты: OOC, просьба, сюжетные слова, длинное описание, резкое действие. Во время интимной сцены не прерывает. «Встряхнуть» — по кнопке. |
| Голоса персонажей | M15 `voices` | Карточки присутствующих: речь (LING и блок Linguistics), MBTI с H/U и состоянием, отношение к персоне (было/стало), связи между присутствующими, цели. Укладываются в бюджет «Голоса» архитектора или в свой предел. Тихий режим: вставка CK `script_inject_carrot-consistency` убирается из собранного промпта (настройки CK не трогаются), DES-RU получает `ck.consistencyRebuild` и отдаёт его обратно при выключении. Выключено по умолчанию. |
| Условные блоки | M34 п.8 | Синтаксис сверен с исходниками ST 1.19 (`core-macros.js:134-213`). В редакторе блока: «Условие» — «Всегда» / «Только когда …» / «Кроме когда …» / «Иначе»; правка уходит в слой. Вкладка «Условия» с симулятором флагов. Предупреждения анализа о битом синтаксисе и пустых сообщениях. При выключенном новом движке макросов — красная плашка. «Подготовить к отключению» спрашивает: оставить текстом или выключить. |

## Найдено и исправлено при сборке
- Режиссёр смотрел только на ответ модели. «Бросаюсь на бандитов» после спокойного ответа оставляло «Диалог». Теперь твоё сообщение тоже решает.
- Резкое действие без сюжетных слов не глушило заметку режиссёра. Теперь это тоже считается, что сюжет ведёшь ты (причина «ясное действие в сцене»).
- Анализ пресета принимал `{{if cond::text}}` за встроенную форму. По исходникам ST встроенная — только `{{if::cond::text}}`.
- Адаптер DES-RU получил `claim`/`release`: модули берут и отдают функции DES-RU, не затирая чужие.
- Архитектор теперь измеряет бюджет «Голоса»; карточки сами укладываются в него.
- Подсказка режима «Экономный» исправлена: режиссёр там ставит флаги, но не пишет заметок.

## Не проверено вживую (проверено тестами)
- Заметка режиссёра при настоящем застое; «Встряхнуть»; модель для сомнительных сцен.
- Гашение вставки CK: на стенде CK не прислал вставку («в прошлый раз CK ничего не прислал»).
- Условный блок в настоящем пресете с генерацией и `/setvar`; «Подготовить к отключению» с условными блоками.
- Как DeepSeek V4 относится к системной заметке на глубине 0.
