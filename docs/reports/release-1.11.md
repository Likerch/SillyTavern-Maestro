## Ограничения

- Данные DES, общие для всех чатов (портрет, внешность в Workshop), сами по себе вопрос не вызывают: неизвестно, какой чат их записал. Портреты по чатам ведёт NAI Studio 0.14.
- Штатное сканирование лора ST, CarrotKernel и NAI Studio по-прежнему включают записи тёзки по ключевым словам; фильтруются только потребители Maestro и паспорта, которые Maestro передаёт NAI Studio.
- Поле «Одежда» добавляется в активный пресет трекера DES; при переключении на персонажа с другим пресетом предложение появится снова.
- Формулировка из «Внешности» не запоминается как «облик» наряда (иначе NAI Studio путал бы наряды по волосам и глазам) — это делается только для поля «Одежда».
- Групповые чаты гардероб по-прежнему не ведёт.

4. Локализация большой книги: счётчик и «Остановить».
5. Общий тон уведомлений; уровень «О чём сообщать».
